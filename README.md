# Scentry

Login and cave-entry automation for Talisman Online.

## Download

Get the latest version from the [Releases](https://github.com/drinzon/Scentry-Releases/releases) page.

Two builds:

* **Scentry-win-Setup.exe** installs Scentry and keeps it updated automatically. Recommended.
* **Scentry-win-Portable.zip** runs without installing. Extract it and run `Scentry.exe`.

Both are fully standalone. No .NET needed. Windows only.

## What it does

* **Login auto retry.** Keeps trying to log in and enter the world on a busy server until it gets you in. Runs up to 10 clients at once and stops on its own when your character loads.
* **Saved accounts.** Stores your game accounts encrypted with Windows DPAPI.
* **Server list.** Add, rename, remove, and reorder servers.
* **Cave entry.** The original right click and left click cave entry spammer.
* **Automatic updates.** Checks for new versions on launch and keeps your settings and accounts.

## Windows SmartScreen Warning

Windows may warn you about this unsigned app. To run it:

1. Click **More info**
2. Click **Run anyway**

The same applies to the installer and the portable build.
